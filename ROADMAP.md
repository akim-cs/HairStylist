# Feature Roadmap

## High Priority

- **Pricing / Services section** — menu of services (cuts, fades, styling, etc.) with prices; reduces back-and-forth before booking
- **Contact & Hours section** — location, working days/hours, Instagram handle, direct contact info
- **Testimonials** — client quotes placed before the booking section for social proof

## Medium Priority

- **Instagram feed** — auto-pulls latest posts to keep the portfolio fresh without touching code
- **Availability management** — way for Andy to mark days off so clients can't book on unavailable dates

## Later

- **Admin dashboard** — private page to view all upcoming bookings without logging into Firebase
